## 01_小星星漂移示範

同一句（第一句）五聲部，只靠 pan 與音量區分。要更接近真實配置，可把其中幾軌換成自己 humming 或 kalimba 錄的同一句。

| 檔案 | 長度 | 內容 |
|---|---|---|
| `01_小星星_五聲部獨立漂移.wav` | 100 s | 前 10 秒完全同步，之後各自 random walk（上限 ±14 cents），不重新同步 |
| `02_小星星_五聲部耦合漂移.wav` | 100 s | 與 01 相同亂數，加 COUPLING=0.8：各聲部被拉向平均值，一起走音、彼此拉開得慢 |
| `03_小星星_漂移後重新同步.wav` | 100 s | 漂移到 58 秒觸發 SYNC，速率 2.5 秒滑回原速，67.8 秒（下一個半句邊界）硬拉回句首，之後乾淨。**最接近子翎要的結構** |
| `04_小星星_只動音準不動時間.wav` | 58 s | 對照組：固定 detune（0／+5／−7／+11／−3 cents）但時間對齊，等於 Pitch Hack 的效果 |
| `05_小星星_漂移與glitch事件.wav` | 100 s | 漂移中插入 tape stop、buffer freeze、反轉、八度斷裂各一次，68 秒 SYNC、77.5 秒對齊 |
| `06_小星星_完整主題_wow_flutter.wav` | 37 s | 完整三句單聲部，只加 wow（±25 cents 慢速不規則）與 flutter（8.5 Hz ±3 cents） |
| `07_小星星_四聲部漂移加半速低八度.wav` | 100 s | 四聲部漂移同 01，多一個 rate 0.5 的低八度聲部墊底 |

## 03_素材層（stems）

全部是單軌或已處理好的層，可以各自拉進 timeline 疊。

**小星星五聲部（各 100 s，44.1k 單聲道）**
`小星星_第一句_聲部1..5_漂移58s重同步_67.8s起乾淨.wav`：0 到 8 秒原速；之後各自漂移（上限 ±18 cents）；58 秒起滑回原速；67.8 秒硬對齊句首；之後是原速乾淨循環到 100 秒。五軌同時播放就是 03 號示範，pan 與音量自己決定。要做「散開再收回、結尾純淨」，用這五軌加 `00_素材切段` 的完整主題接尾即可。
`小星星_第一句_低八度半速聲部_漂移58s重同步.wav`：rate 0.5，低八度、兩倍長，漂移與重同步時程同上，可墊在下面。
`小星星_三聲部耦合漂移_78s重同步_52-100s.wav`：100 秒時間軸，內容在 52 到 100 秒。低八度慢速加兩個原速聲部，低通 2.6 kHz、大殘響，78 秒 SYNC、90.8 秒對齊。這是氛圍版，比較糊。

**ㄅㄆㄇㄈ phase loop（各 60 s，48k 單聲道，無殘響）**
`ㄅㄆㄇㄈ_柏豪_phase聲部1..4_±cents_40s重同步.wav`：柏豪「ㄅㄆㄇㄈ」循環，偏移 0／+6／−6／+12 cents，40 秒起收回、47 秒對齊。四軌一起就是 08 的乾淨版。

**注音三人交錯（100 s 時間軸，內容在 0 到 48 秒，48k 立體聲）**
`注音_三人依序分段交錯_乾淨版_0-48s.wav`：ㄅㄆㄇㄈ 阿瑤先念、柏豪與小軒追進來、三人同念一次相位錯開；ㄉㄊㄋㄌ 到 ㄐㄑㄒ 輪流一人一段、下一位在段尾前接上；ㄓㄔㄕㄖ 到 ㄞㄟㄠㄡ 三人同念、相位逐段拉開；ㄢㄣㄤㄥ、ㄦ、ㄧㄨㄩ 漸慢散開，最後 ㄧㄨㄩ 三人各一次反轉收尾（2026-09-03 依校正後的順序與邊界重出）。只有每人固定微 detune 與小房間殘響，沒有其他效果。

## 相關工具：Tape Drift 網頁與 gen~ 版

`互動音樂測試/tape_drift/`（2026-09-03 早上另一個 session 做的）：

- `tape_drift.html`：單一檔案的網頁工具，拖音檔進去就能播，三個預設「漂移」「交織（原音 + 降 35 cent）」「收斂（60 秒走到準）」，可直接輸出 WAV。不需要伺服器，Finder 雙擊用瀏覽器開即可。**「收斂」預設就是子翎要的「走音慢慢變準、最後純淨」**，把 `00_素材切段/小星星_完整主題_三句_0.52-37.95s_原始.wav` 丟進去、按收斂、輸出，就是一個可用的結尾。
- `tape_drift_gen.txt`：同一套演算法的 `gen.codebox~` 版，貼進 Max 或 M4L 就是即時版，接法見同夾 `tape_drift_gen_說明.md`。這是「自製 M4L 裝置」那條路的最小可跑版本。
- 與本資料夾 Python 引擎的分工：網頁與 gen~ 版是**單聲部、平滑收斂**（正弦加雜訊、無硬對齊），適合結尾；Python 引擎是**多聲部、耦合與量化硬對齊**，適合中段的 ensemble 漂移示範。
