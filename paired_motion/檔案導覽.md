# paired_motion 檔案導覽:要看誰

> 演出主 patch 都在 `paired_motion/patchers/`。這份說明「哪個檔做什麼、要開哪個」。🆕 = 這次新增。

## 要跑演出 → 開這個

| 檔案 | 說明 |
|---|---|
| `paired_motion.maxproj` | Max 專案檔,**從這裡開**(會把整包 abstraction、素材、library 都帶上) |
| `patchers/main.maxpat` | **演出主 patch**。只做接線、混音、輸出;雙擊它跑 |

## 三個感測器各自的處理(一顆感測器一個)

| 檔案 | 處理誰 | 目前輸出 |
|---|---|---|
| `patchers/sub_pressure.maxpat` | 雙手握力 FSR | 廣播 `hand1`/`hand2`(0~1),控制**載入音檔的音量** |
| `patchers/sub_tof.maxpat` | 兩顆 ToF 距離/速度 | 位置 + 帶號速度;內含送 Ableton 的 `noteout` |
| `patchers/sub_piezo.maxpat` | 四片壓電敲擊 | 敲擊事件 + 連續串流;內含 `noteout` |
| `patchers/sub_auto_detect.maxpat` | USB port 自動辨識 | WHO 握手,把對的 port 餵給各 `[serial]` |

## 🆕 這次新增(合奏聲部 + 方向)

| 檔案 | 說明 |
|---|---|
| `patchers/sub_voice_gate.maxpat` | 🆕 **核心**:每手一個獨立聲部閘門(Schmitt 遲滯)→ `voice1`/`voice2`/`activeVoices` |
| `patchers/sub_direction.maxpat` | 🆕 ToF 兩軸帶號速度 → 上/下/左/右 + 力度 |
| `patchers/test_voice_gate.maxpat` | 🆕 **免硬體測試台**,拖 slider 就能驗上面兩個(先開這個看邏輯) |

> 這套邏輯的流程圖(含圖片與 Mermaid)在 Obsidian:`Projects/藝術進駐工研院/數位同動車 聲部與方向 邏輯圖.md`。

## 輔助 / 其他(平常不用動)

- `patchers/main_viz.maxpat`、`patchers/sub_visualization.maxpat`:ToF 軌跡視覺化版本
- `patchers/p_resonators~.maxpat`、`p_resontaps~.maxpat`:共振器 abstraction(被 sub_tof/sub_piezo 用)
- `patchers/vs.*.maxpat`:Cycling74 vs library 的工具 abstraction
- `code/`:USB 自動偵測的 node.js(凍結副本)
- `data/`、`media/`:聲音素材與快照

## 檢閱這次新功能的順序

1. 先開 `patchers/test_voice_gate.maxpat` → 拖 slider 看邏輯對不對。
2. 對照 Obsidian 的「數位同動車 聲部與方向 邏輯圖」流程圖理解。
3. OK 之後,才談把 `sub_voice_gate` 接進 `main.maxpat` / `sub_tof.maxpat`(尚未做)。
